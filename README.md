# وسم

أداة مبسّطة لنظام iOS لإضافة مصادر التطبيقات المتوافقة مع صيغة AltStore، وتصفّح تطبيقاتها، وتثبيتها بضغطة واحدة باستخدام شهادة توقيع خاصة، مع التنبيه عند توفر تحديث لأي تطبيق مثبّت.

## المزايا

- **المتجر:** إضافة المصادر وإدارتها، وتصفّح التطبيقات والبحث فيها، وصفحات تفاصيل تتضمن الصور والوصف وسجل الإصدارات.
- **التثبيت بضغطة واحدة:** يُنزَّل التطبيق ويُوقَّع بالشهادة المحددة ويُثبَّت في الخلفية.
- **تطبيقاتي:** قائمة التطبيقات المثبّتة من المصادر، مع فحص تلقائي للتحديثات يقارن رقم الإصدار ورقم البناء، وزر «تحديث» و«تحديث الكل».
- **الإعدادات:** خيارات تثبيت افتراضية تُطبَّق تلقائيًا، وخيار لإظهار شاشة الخيارات قبل التثبيت، وخيار لإظهار سجل العمليات.
- **إشعار التحديث:** يتحقق التطبيق عند التشغيل من آخر إصدار منشور في هذا المستودع.

## التثبيت

يُنزَّل ملف `Muthabbit.ipa` من صفحة الإصدارات، أو من مصدر تطبيقات za7ef:

```
https://raw.githubusercontent.com/za7ef/apps-source/main/source.json
```

## البناء

يُبنى التطبيق تلقائيًا عبر GitHub Actions عند كل دفع إلى الفرع الرئيسي، ويُنشر ملف IPA غير موقّع في إصدار جديد يحمل الوسم `v<الإصدار>-b<رقم البناء>`.
